# Сервис подбора культурных мероприятий

Босарев Евгений Вадимович, ЭФБО-11-24, 2026.

Приложение помогает посетителю выбрать культурное мероприятие по интересам,
возрасту и бюджету. Аудитория — жители города, студенты и туристы.
Основные сущности: пользователь, интерес, мероприятие, рекомендация.

## Этапы
- `pr1`: проверка интереса, доступности по возрасту и дате, бюджета.
- `pr2`: каталог, поиск, сортировка, пользователи, рекомендации, JSON.
- `pr3`: те же сценарии с классами и связями между объектами.

## Запуск
Нужен Python 3.9 или новее. Приложение использует стандартную библиотеку.
Из папки нужной практики выполнить `python main.py`.
ПР1 показывает один сценарий, ПР2 и ПР3 открывают консольное меню.
В ПР2/ПР3 исходные демонстрационные данные лежат в `seed.json`.
Изменения записываются в `data.json` рядом с программой.

## Проверка
Из корня репозитория: `python -m pip install -r requirements-dev.txt`.
Затем в `pr2` и `pr3`: `python -m pytest -q` и `python -m flake8`.
История: `git log --oneline`. Контрольные точки: `pr1`, `pr2`, `pr3`.

## Дальнейшее развитие
Django, регистрация и вход, ORM и база данных, веб-каталог, личный кабинет,
административное управление событиями, API. На текущем этапе интерфейс
консольный. Рекомендации формируются по совпадению интересов.
