# Сервис подбора культурных мероприятий

Выполнил: Босарев Евгений Вадимович, ЭФБО-11-24.

Это учебный консольный проект. Он хранит пользователей и мероприятия, а затем подбирает события по интересам, возрасту, дате и бюджету пользователя.

## Структура проекта

- `pr1` — простой пример из трёх функций;
- `pr2` — каталог, поиск, рекомендации и сохранение в JSON;
- `pr3` — та же программа, но данные представлены классами;
- `requirements-dev.txt` — pytest и flake8 для проверки проекта.

Каждая папка показывает отдельный этап разработки. Для демонстрации лучше использовать `pr3`, потому что это последняя версия.

## Как запустить

Нужен Python 3.9 или новее. Дополнительные библиотеки для самой программы не требуются.

```bash
cd pr3
python main.py
```

В меню можно посмотреть каталог, выполнить поиск, добавить пользователя, получить рекомендации, отклонить рекомендацию и вывести статистику.

Исходные данные находятся в `seed.json`. После изменений программа создаёт `data.json`. Чтобы снова начать с исходных данных, достаточно удалить `data.json`.

## Как проверить

```bash
python -m pip install -r requirements-dev.txt
cd pr3
python -m pytest -q
python -m flake8
```

Тесты проверяют поиск, подбор рекомендаций, обработку неправильных данных и сохранение в JSON. Метки Git `pr1`, `pr2`, `pr3` соответствуют трём практическим работам.

## Как работает подбор

Мероприятие попадает в рекомендации, если оно активно, ещё не прошло, подходит по возрасту и бюджету и имеет хотя бы один общий интерес с пользователем. Сначала выводятся события с большим числом совпавших интересов. При одинаковом числе совпадений раньше выводится более дешёвое событие.
