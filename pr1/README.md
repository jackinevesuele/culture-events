# Практическая работа 1

На первом этапе реализован простой подбор одного мероприятия. В программе есть три функции.

## Функции

### `matches_interest(user_interest, event_interest)`

Сравнивает интерес пользователя с темой мероприятия. Регистр и пробелы по краям не учитываются. Например, `фотография` и `Фотография` считаются одинаковыми.

### `is_available(age, min_age, event_date, today)`

Проверяет два условия: пользователю хватает возраста и дата мероприятия ещё не прошла. Функция возвращает `True`, только если выполнены оба условия.

### `fits_budget(price, budget)`

Проверяет, что цена неотрицательная и не превышает бюджет пользователя.

## Как работает программа

В `main.py` задан пример: пользователю 20 лет, его интерес — фотография, бюджет равен 600 рублям. Выставка стоит 400 рублей и проходит сегодня. Все три проверки дают положительный результат, поэтому программа пишет, что мероприятие подходит, и показывает остаток бюджета 200 рублей.

## Запуск

```bash
python main.py
```

Для проверки отрицательного результата можно временно установить бюджет 300 рублей, возраст 10 лет или другой интерес. Тогда мероприятие не будет рекомендовано.

## Что показать преподавателю

Запустить `python main.py` и объяснить три проверки: совпадение интереса, доступность по возрасту и дате, соответствие бюджету. Итоговое сообщение появляется только тогда, когда пройдены все проверки.
