# Практическая работа 2

Во второй работе появился каталог из нескольких мероприятий, пользователи, поиск, рекомендации и сохранение данных в JSON.

## Файлы

- `main.py` — консольное меню и ввод данных;
- `service.py` — функции поиска, подбора и статистики;
- `storage.py` — загрузка и сохранение JSON;
- `seed.json` — начальные данные;
- `tests/test_service.py` — автоматические тесты.

## Основные функции

- `find_by_id` ищет объект по номеру и сообщает об ошибке, если его нет;
- `next_id` создаёт следующий свободный номер;
- `add_user` проверяет имя, возраст, бюджет и интересы, затем добавляет пользователя;
- `search_events` ищет часть названия без учёта регистра и сортирует события по дате;
- `is_suitable` проверяет активность, дату, возраст, бюджет и совпадение интересов;
- `recommend` формирует рекомендации и сортирует их по числу совпавших интересов и цене;
- `dismiss` меняет статус рекомендации на `dismissed`;
- `statistics` считает пользователей, мероприятия и новые рекомендации;
- `load_data` и `save_data` читают и записывают JSON.

## Как запустить

```bash
python main.py
```

Команды меню:

- `1` — показать каталог;
- `2` — найти мероприятие по названию;
- `3` — добавить пользователя;
- `4` — подобрать мероприятия пользователю;
- `5` — отклонить рекомендацию;
- `6` — показать статистику;
- `7` — показать интересы и пользователей;
- `0` — выйти.

При первом запуске используются данные из `seed.json`. После изменения данные сохраняются в `data.json` и загружаются оттуда при следующем запуске.

## Проверка

```bash
python -m pytest -q
python -m flake8
```

Тесты проверяют поиск, ограничения по возрасту, дате и бюджету, порядок рекомендаций, повторный подбор и сохранение данных.
