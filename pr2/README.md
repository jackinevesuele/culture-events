# Практическая работа 2
`main.py` — меню, `service.py` — подбор и обработка коллекций,
`storage.py` — JSON. Запуск: `python main.py`.
Поиск выполняется по части названия. Подбор исключает прошедшие,
отменённые, слишком дорогие и недоступные по возрасту события.
Сначала идут события с большим количеством совпадений интересов,
затем более дешёвые. Повторный подбор обновляет рекомендации пользователя.
`python -m pytest -q` запускает тесты, `python -m flake8` — проверку стиля.
