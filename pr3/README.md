# Практическая работа 3
Запуск: `python main.py`. Проверка: `python -m pytest -q`, `python -m flake8`.
Основные классы находятся в `models.py`:
- Interest — интерес пользователя или тема события;
- User — имя, возраст, бюджет и коллекция интересов;
- Event — дата, цена, возрастное ограничение и проверка соответствия;
- Recommendation — ссылки на пользователя и событие, балл и статус.

`Event.is_suitable()` заменяет одноимённую функцию ПР2.
`Recommendation.dismiss()` изменяет состояние конкретной рекомендации.
Поиск и обработка коллекций остались функциями `service.py`.
JSON хранит идентификаторы связей; загрузка восстанавливает ссылки на объекты.
`main.py` отвечает за ввод и вывод, `storage.py` — за файлы.
Статус рекомендации доступен через свойство, изменение выполняет метод.
У каждого класса есть `__init__`, `__str__`, `to_dict`.
Наследование не применяется: ни одна из четырёх сущностей не является
частным случаем другой. Общий вызов `str()` показывает полиморфизм.
