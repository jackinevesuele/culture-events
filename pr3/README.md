# Практическая работа 3

В третьей работе данные из словарей заменены объектами. Возможности ПР2 сохранены: каталог, поиск, пользователи, рекомендации, статистика и JSON.

## Файлы

- `main.py` — меню программы;
- `models.py` — классы предметной области;
- `service.py` — функции для работы с коллекциями объектов;
- `storage.py` — преобразование объектов в JSON и обратно;
- `seed.json` — начальные данные;
- `tests/test_service.py` — тесты.

## Классы

### `Interest`

Хранит номер и название интереса. Метод `to_dict` подготавливает данные для JSON.

### `User`

Хранит номер, имя, возраст, бюджет и список интересов. Конструктор проверяет имя, возраст и бюджет. Метод `__str__` создаёт понятную строку для вывода в меню.

### `Event`

Хранит название, дату, цену, возрастное ограничение, интересы и признак активности. `score_for` считает общие интересы с пользователем. `is_suitable` проверяет, подходит ли мероприятие по всем условиям.

### `Recommendation`

Связывает объекты пользователя и мероприятия, хранит балл и статус. Метод `dismiss` переводит рекомендацию в статус `dismissed`. Свойство `status` позволяет получить текущий статус.

У всех классов есть `to_dict`, чтобы сохранить объекты в JSON. При загрузке `storage.py` сначала создаёт интересы, пользователей и мероприятия, а затем восстанавливает связи между ними по идентификаторам.

## Функции сервиса

- `find_by_id` и `next_id` работают с номерами объектов;
- `add_user` создаёт объект пользователя;
- `search_events` выполняет поиск и сортировку;
- `recommend` вызывает методы мероприятий и создаёт объекты рекомендаций;
- `dismiss` отклоняет выбранную рекомендацию;
- `statistics` возвращает основные количества.

Поиск и сортировка оставлены обычными функциями, потому что они работают сразу с коллекцией объектов. Проверки конкретного мероприятия находятся в классе `Event`, потому что относятся к его данным.

## Запуск и проверка

```bash
python main.py
python -m pytest -q
python -m flake8
```

Меню используется так же, как в ПР2. Для быстрой демонстрации: `1` показывает каталог, `7` — пользователя и интересы, `4` и затем `1` — рекомендации, `6` — статистику, `0` — выход.
